# Учебная папка

Откройте папку `lesson-09-starter` в VS Code и запустите корневой `index.html`: в нём ссылки на все примеры, прогнозы и заготовки. Страницы можно открыть как файлы или через Live Server.

- `demo` – готовые примеры и их CSS в `demo/css`.
- `probes/P1`–`probes/P5` – отдельные исходники прогнозов; у каждого свой `css/style.css`. После проверки верните исходный код.
- `A`, `B`, `C` – заготовки самостоятельных заданий. Для задания D создайте папку `workshop` здесь же.

Пути внутри папки относительные. Условия и последовательность действий находятся в раздатке.
